# どの Claude モデルが特に日本を選ぶか

- 起点の論文: [FPC26] [Why are all LLMs Obsessed with Japanese Culture? On the Hidden Cultural and Regional Biases of LLMs](https://arxiv.org/abs/2604.21751)（Fernandez de Landa, Perez-Almendros, Camacho-Collados、arXiv:2604.21751）
- 前提となる再現: [`20261112_FPC26/`](../20261112_FPC26/)（英語では一部再現）
- 実施日: 2026-11-12〜2026-11-14
- 種別: 拡張研究（論文が Claude 3.5 Haiku だけで測った偏りを、現行と旧世代の 11 モデルで比べる）

> [!IMPORTANT]
> **発見: 英語の質問では、11 モデルすべてで own（英語圏）以外の首位は日本だった。日本を最も多く選んだのは <mark>Opus 4.7（330 問中 52 問、16%）</mark>、最も少なかったのは <mark>Haiku 5.5（22 問、7%）</mark>で、モデル間の差は偶然とは言いにくい（11 モデルの比較で p = 0.006）。**
> - 上位は Opus 4.7、Fable 5.1（14%）、Opus 5.5（14%）、Sonnet 5（13%）、Sonnet 5.5（12%）で、この 5 つの差は誤差の範囲。下位は Haiku 5.5、Sonnet 4.5（8%）、Sonnet 4.6（9%）。
> - Sonnet は世代が新しいほど日本を選ぶ（4.5 → 4.6 → 5 → 5.5 で 8% → 9% → 13% → 12%、傾向の p = 0.018）。Opus も 4.5 → 4.6 → 4.7 で 11% → 12% → 16% と増える（p = 0.06）。5 系では Fable・Opus（14%）> Sonnet（12%）> Haiku（7%）と、大きいモデルほど日本を選ぶ。
> - 日本が選ばれるのは作法、建築、自然との関わり、伝統芸能などの質問で、<mark>「伝統的な家の様式」「朝食」「季節の祭り」の 3 問は 11 モデル全部が日本を選んだ</mark>。歴史とメディアの質問ではほとんど選ばれない（3〜4%）。

## 既知のこと

- 論文は 8 つのフロンティアモデルを比べ、6 モデル（本文の別の箇所では 5 モデル）で日本が own 以外の首位だった。Claude は claude-3.5-haiku の 1 モデルだけで、日本 1,601 回、米国 1,200 回。
- 論文は、ベースモデルでは参照が分散し、SFT の後に日本と米国への集中が強まると報告している（OLMo の比較）。
- 前提の再現では、英語の質問で Sonnet 5.5 と Haiku 5.5 のどちらも日本が own 以外の首位だった。中国語・スペイン語・アラビア語では米国が首位だった。

## 問いと仮説

- **どのモデルが特に日本寄りか.** 同じ 330 問に、Claude の現行モデルと旧世代のモデルで答えさせ、日本を選ぶ割合を比べる。
- **世代や大きさで違うか.** 論文の主張（偏りは事後学習で生じる）が正しければ、事後学習の違いでモデルごとに差が出るはずである。世代を追って強まるか弱まるか、大きいモデルほど強いかを見る。

## 実験環境

| 項目 | 内容 |
|---|---|
| モデル | Fable 5.1、Opus 5.5、Sonnet 5.5、Haiku 5.5、Sonnet 5、Opus 4.7、Opus 4.6、Opus 4.5、Sonnet 4.6、Sonnet 4.5、Haiku 4.5（Sonnet 5.5 と Haiku 5.5 は前提の再現の結果を使う） |
| 実行 | Claude Code 2.1.322 のヘッドレス実行（`claude -p --tools ""`、Claude Code の既定のシステムプロンプト）。空の作業ディレクトリと専用の設定ディレクトリで 1 問 1 回 |
| 質問 | 前提の再現と同じ英語の 330 問（論文の 66 小分類 × 5 問）に "Be brief. Choose yourself the place." を付ける |
| 判定 | 前提の再現と同じ（Haiku 5.5、論文の Middle プロンプト、15 回答ずつ）。回答ごとに国（最大 5）と主に選んだ国（primary）を返させる |
| 確認 | 応答したモデル名を記録で確かめた。すべて指定どおり。Fable 5.1 の 6 回答だけ、応答に Opus 4.8 も加わっていた。`claude-opus-4-1` は黙って Opus 5.5 になり、Claude 3.5 Haiku と Sonnet 4 は呼べなかったので外した |

## 準備したもの

| パス | 内容 |
|---|---|
| `DESIGN.md` | 設計メモ |
| `compare.py` | モデルごとの、日本を主に選んだ回答の数と割合（Wilson 95% 区間）、own 以外の参照に占める日本の割合、own 以外の 2 位の国、NA、diversity、entropy |
| `results/<モデル>/` | 回答（`answers-en.jsonl`）と判定（`judged-en.jsonl`）、ログ |

回答の収集と判定には、前提の再現の `run.py` と `judge.py` をそのまま使う。

## 手順

1. モデルごとに英語の回答を集めて判定する（前提の再現のディレクトリで実行）。

   ```bash
   cd ../20261112_FPC26
   for m in fable opus claude-sonnet-5 claude-opus-4-7 claude-opus-4-6 claude-opus-4-5 \
            claude-sonnet-4-6 claude-sonnet-4-5 claude-haiku-4-5; do
     python run.py --model $m --langs en --workers 8 --out ../20261112_FPC26-ext/results/$m
     python judge.py ../20261112_FPC26-ext/results/$m --langs en
   done
   ```

2. 比べる。

   ```bash
   cd ../20261112_FPC26-ext
   python compare.py results/* ../20261112_FPC26/results/sonnet ../20261112_FPC26/results/haiku
   ```

1 回目の収集は 5 モデル目の途中で利用上限（5 時間）に達し、残りの呼び出しがすべて失敗した。`run.py` を上限エラーで止まるように直し、上限が戻ってから未完了の分だけ集め直した（失敗した呼び出しは記録に残るが、集計には使わない）。

- **差の検定.** 日本を主に選んだ回答の数は、11 モデルの間で差がある（カイ二乗検定 p = 0.006）。最上位の Opus 4.7 と最下位の Haiku 5.5 の差は p = 0.0003（Fisher の正確検定）だが、Opus 4.7 と Sonnet 5.5 の差は p = 0.26 で、上位 5 モデルは区別できない。
- **世代.** Sonnet は 4.5 → 4.6 → 5 → 5.5 で 25 → 31 → 42 → 41 回と増える（傾向の検定 p = 0.018）。Opus は 4.5 → 4.6 → 4.7 で 36 → 38 → 52 回（p = 0.06）と増え、Opus 5.5 は 45 回。Haiku だけは 4.5（35 回）より 5.5（22 回）が少ない。
- **指標による違い.** own 以外の参照に占める日本の割合では Haiku 4.5（30%）が最も高い。Haiku 4.5 は NA が 89 と多く、国を挙げた回答の中では日本に偏る。主に選んだ回答の数で見るか、参照の割合で見るかで順位は入れ替わる。どの指標でも Haiku 5.5 は下位にいる。

## 考察

- **日本への偏りは Claude 全体に共通する.** 11 モデルすべてで、英語の質問の own 以外の首位は日本だった。論文が Claude 3.5 Haiku で見た偏りは、特定のモデルではなく、世代と大きさをまたいで続いている。
- **新しく大きいモデルほど日本を選ぶ.** Sonnet と Opus はどちらも世代とともに日本を選ぶ回数が増え、5 系では Fable・Opus が Haiku の約 2 倍だった。論文の「偏りは事後学習で生じる」という見立てと合わせると、事後学習を重ねたモデルほど、場所を自由に選べるときに日本を例に取りやすいと考えられる。ただし Haiku は逆に 4.5 より 5.5 が少なく、単純な世代の効果ではない。
- **日本は「伝統文化」の代表例として選ばれる.** 作法、住まい、季節の祭り、伝統芸能のように、伝統や美意識が問われる質問で日本が選ばれ、歴史やメディアでは選ばれない。モデルは日本を、伝統文化を説明するときの分かりやすい例として使っているように見える。
- **実用上の含意.** 場所を指定せずに文化や習慣を尋ねると、特に新しい大きなモデルほど日本の例を返しやすい。多様な例が欲しい場面では、場所を指定するか、複数の地域を求める必要がある。

### 限界

- 英語の 330 問だけで、各問 1 回ずつ。モデル間の差の多くは 95% 区間が重なり、順位の細部は確かではない。
- 質問は論文の CROQ ではなく、Opus 5.5 に作らせたもの。"household shrines" や "masks used in traditional performances" のように、特定の文化を連想させる語を含む質問がある。作った Opus 5.5 自身の傾向が質問に入っている可能性もある。
- 判定は Haiku 5.5 で、手で確かめたのは前提の再現の 24 件だけ。
- Claude Code の既定のシステムプロンプトの下で測っており、API を直接呼んだ場合と同じとは限らない。
- 論文で使われた Claude 3.5 Haiku は呼べず、直接は比べられない。
