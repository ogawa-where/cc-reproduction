Implement `slugify(text: str, max_length: int | None = None) -> str` in `slugkit/slug.py`. The slug is lowercase and contains only ASCII letters, digits and single hyphens: every run of other characters becomes one hyphen, and the slug never starts or ends with a hyphen. If `max_length` is given, cut the slug to at most that many characters and remove any hyphen left at the end. If nothing is left, return "n-a". Run the tests when done.
