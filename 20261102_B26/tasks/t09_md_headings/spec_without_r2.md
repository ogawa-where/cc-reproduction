Implement `extract_headings(markdown: str) -> list[tuple[int, str]]` in `mdtoc/headings.py`, which returns the ATX headings of a Markdown document as `(level, text)` pairs in document order. A heading line starts with 1 to 6 `#` characters followed by at least one space and the heading text; the level is the number of `#`, and the text has surrounding whitespace stripped. An optional closing run of `#` characters preceded by a space is not part of the text, so "## Setup ##" gives `(2, "Setup")`. Lines with seven or more leading `#`, or with no space after the `#` run (such as "#hashtag"), are not headings. Run the tests when done.
