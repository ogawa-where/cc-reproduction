Implement the `LRUCache` class in `lrucache/cache.py`: `LRUCache(capacity: int)` with `get(key, default=None)`, `put(key, value) -> None`, `__len__` and `__contains__`. `get` returns the stored value, or `default` when the key is missing. When `put` adds a new key while the cache already holds `capacity` entries, it first evicts the least recently used entry. Both `get` on an existing key and `put` on an existing key count as a use and make that key the most recently used; `put` on an existing key only updates the value and never evicts anything, while a membership test (`key in cache`) does not count as a use. A capacity below 1 raises `ValueError`. Run the tests when done.
