Implement the `LRUCache` class in `lrucache/cache.py`: `LRUCache(capacity: int)` with `get(key, default=None)`, `put(key, value) -> None`, `__len__` and `__contains__`. `get` returns the stored value, or `default` when the key is missing. When `put` adds a new key while the cache already holds `capacity` entries, it first evicts the least recently used entry. A capacity below 1 raises `ValueError`. Run the tests when done.
