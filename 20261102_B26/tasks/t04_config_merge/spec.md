Implement `deep_merge(base: dict, override: dict) -> dict` in `confmerge/merge.py`, which layers an override config on top of a base config. The result contains the keys of both dicts; when a key is in both and either value is not a dict, the override value wins, and lists are treated as plain values that replace each other. When both values are dicts, they are merged recursively by the same rules. An override value of `None` removes that key from the result, at any nesting level. Neither input may be modified, and the result must be fully independent of the inputs (no shared nested dicts or lists), so changing the result later never affects `base` or `override`.
