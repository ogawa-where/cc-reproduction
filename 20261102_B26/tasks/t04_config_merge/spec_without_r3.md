Implement `deep_merge(base: dict, override: dict) -> dict` in `confmerge/merge.py`, which layers an override config on top of a base config. The result contains the keys of both dicts; when a key is in both and either value is not a dict, the override value wins, and lists are treated as plain values that replace each other. When both values are dicts, they are merged recursively by the same rules. An override value of `None` removes that key from the result, at any nesting level. Run the tests when done.
