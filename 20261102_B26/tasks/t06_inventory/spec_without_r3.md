Implement the `Inventory` class in `stock/inventory.py` with the methods `add(sku: str, qty: int) -> None`, `remove(sku: str, qty: int) -> None`, `quantity(sku: str) -> int` and `report() -> list[tuple[str, int]]`. Adding the same SKU again accumulates its quantity, and `quantity` returns 0 for a SKU that was never added. Removing more units than are in stock raises the existing `InsufficientStock` exception and leaves the stock unchanged. `report` lists the items whose quantity is positive as `(sku, quantity)` pairs, sorted by quantity from highest to lowest, with ties ordered by SKU alphabetically.
