Implement `parse_csv(text: str, delimiter: str = ",") -> list[dict[str, str]]` in `csvlite/parser.py`. The first line is the header row, and every following row becomes a dict that maps each header name to that row's value in the same position; values are returned as strings exactly as written, apart from removing quotes. A field may be wrapped in double quotes, in which case it can contain the delimiter, and a doubled quote (`""`) inside a quoted field stands for one literal quote character. Blank lines are skipped wherever they appear, and a line that contains only whitespace counts as blank. If a data row has a different number of fields than the header, raise `ValueError`. Fields never span multiple lines. Run the tests when done.
