Implement `compare_versions(a: str, b: str) -> int` and `sort_versions(versions: list[str]) -> list[str]` in `verkit/version.py`. `compare_versions` returns -1, 0 or 1 when `a` is lower than, equal to or higher than `b`. A version is one or more dot-separated non-negative integers, compared numerically from left to right, so "1.10" is higher than "1.9". Missing trailing components count as zero, so "1.2" and "1.2.0" are equal. A version may end with a pre-release label after a hyphen, as in "2.0.0-rc1"; a pre-release is lower than the same version without a label, and two labels are compared as plain strings. Anything else, including an empty string, an empty component or a non-numeric component, raises `ValueError`. `sort_versions` returns a new list sorted from lowest to highest by the same ordering, keeping the original order of versions that compare equal.
