Implement `tokenize(expr: str) -> list[tuple[str, str]]` in `calclex/lexer.py`, which returns the tokens of an arithmetic expression as `(kind, text)` pairs. The kinds are "NUM" for numbers, "OP" for `+ - * /`, "LPAREN" and "RPAREN"; whitespace separates tokens and is otherwise ignored. Numbers are integers or decimals such as "3.14", "10." or ".5", and each one is a single NUM token. A minus sign is unary when it comes at the start of the expression or directly after an operator or "(", and then it becomes part of the number that follows it, so "-3*(-2)" gives NUM "-3", OP "*", LPAREN, NUM "-2", RPAREN, while "5-3" gives NUM, OP, NUM. Any other character raises the existing `LexError`, whose `pos` attribute must be the 0-based index of the offending character. Run the tests when done.
