# 画像の図形がコードの書き方を誘導する現象の再現

- 論文: [TWWWKL26] [A Heart Means Recursion: Exploring Visual Meaning and Communication in VLMs](https://arxiv.org/abs/2610.36449)（Alexa Tartaglini, Zhengxuan Wu, Thaddäus Wiedemer, Martin Wattenberg, Been Kim, Yuxuan Li、Google DeepMind / Stanford、arXiv:2610.36449）
- 論文の公開日: 2026-10-27（v1）
- 再現日: 2026-11-01

> [!IMPORTANT]
> **再現できた（Opus 5.5）。** 課題と無関係な図形の画像が、二分木の中順走査の解き方を再帰へ誘導した。赤い螺旋と赤い枝分かれ矢印は 20/20 が再帰（ΔP = +1.0、「再帰で解け」と指示したときと同じ強さ）、赤いハートは Claude Code のシステムプロンプトありで 13/60（+0.22）、最小のシステムプロンプトでは 25/40（+0.62）。同じ内容のキャプションやノイズ画像では 0/20。Sonnet 5.5 はどの図形にもほぼ反応しなかった（最大 1/20）。効く図形は論文の Opus 4.7（三角・ハート・円）と異なり、論文が述べる「誘導の地図はモデルごとに違う」「画像を文脈の末尾に置くと、螺旋や枝分かれ矢印のような意味的な図形が強くなる」と整合する。

## 論文の主張

**背景.** 人は形や色や配置で意味を伝える。VLM（視覚言語モデル）は人の視覚文化を映す何十億枚もの画像で学習しており、視覚的な問題解決は得意になった。だが「画像を通して意味を受け取り、伝える」ことは別の能力である。論文は、VLM が視覚的に意味をやり取りできるかを 3 つの実験で調べ、その出発点として意外な観察を報告する。

**観察した現象（視覚的な誘導）.** 二分木の中順走査（inorder traversal）という、再帰でも反復でも同じように解ける簡単なコーディング問題を出す。プロンプトの先頭に、課題と無関係な「色のついた単純な図形」の画像（400×400、白地）を置き、「画像を見て、コーディング戦略（再帰か反復）を選んで解け」と指示する。各条件で 20 回サンプリングし、再帰で解いた割合 P(recursion) を求め、画像なしの基準との差 ΔP(recursion) を誘導効果とする。

- 画像なしでは Claude Opus 4.7 と GPT-5.4 は 100% 反復で解く（P(recursion) = 0）。Gemini 3.1 Pro は 0.4。
- <mark>赤いハートを置くと、Claude Opus 4.7 と GPT-5.4 は 100% 再帰に切り替わる（ΔP = +1.0）</mark>。Gemini 3.1 Pro では黄色いチェックマークで 90%（ΔP = +0.5）。ハートの効果は「再帰で解け」と直接指示したときの効果（Claude で +1.0）に匹敵する。
- 24 図形 × 12 色 = 288 記号で調べると、モデルごとに誘導の地図が違う。Claude Opus 4.7 は色によらず三角（+0.83）、ハート（+0.79）、円（+0.68）に誘導され、GPT-5.4 は主にハート（+0.54）、Gemini は特定の形と色の組み合わせ（ピンクの十字、シアンの螺旋、+0.50）に反応する。再帰を連想させる「枝分かれした矢印」は Claude を誘導しない。
- 画像の代わりに同じ内容のキャプション（"An image of a red heart" を画像と同じトークン数まで繰り返す）を置いても誘導はほぼ起きない（画像との相関 r = −0.05、Claude）。ガウスノイズや ImageNet の写真でも起きない（ΔP = 0.0）。図形の向きを変えたり画素をシャッフルしたりすると効果は大きく減る。
- 画像の位置で効果が変わる。文脈の先頭に置いたときが最も強く、中ほどに置くと効果はほぼ消える。「選べ」という語を外した言い回しでも、基準が 100% 反復のモデルでは効果がほぼ消える。
- モデルはこの影響を自分では説明できない。思考の過程や直接の自己申告では、画像を無関係として退けていることが多い。

**その他の知見.** モデル同士の視覚的なコミュニケーションでは、送り手が「直感的」と思う図形（人もそう思う）を送るが、それは受け手をあまり誘導しない（生成と解釈のずれ）。抽象概念や物語を図で伝えるゲームでは、創造的に伝え合えるが、人には読み取りにくい図も生まれる。

## 準備したもの

| パス | 内容 |
|---|---|
| `symbols.py` | 12 図形（ハート、三角、円、四角、星、十字、チェックマーク、螺旋、枝分かれ矢印、不定形、×、右矢印）× 12 色の 400×400 PNG と、ガウスノイズ画像を描画する |
| `classify.py` | 解答の Python コードを AST で recursive / iterative / other に分類する |
| `run.py` | 条件ごとに `claude -p` を呼び、解答と分類を `runs/samples-<model>.jsonl` に記録する。条件は `baseline`、`image:<図形>:<色>`、`silent:…`、`caption:…`、`text:recursive`、`noise`、`shapes:<色>`、`colors:<図形>` |
| `summarize.py` | 条件ごとの P(recursion)、Wilson 95% 区間、基準との差 ΔP、図形別・色別の平均 |

## 手順

1. `python symbols.py symbols` で記号画像を描画する。
2. 条件ごとに、論文のプロンプトを組み立てる。画像条件は「画像 → 指示 → 問題文」の順で、戦略の提示順（recursion or iteration / iteration or recursion）を交互に 10 回ずつ。基準は画像なしで「好みで選べ」、テキスト指示は「再帰で解け」、キャプションは画像の代わりに "An image of a red heart." を 40 回繰り返す。
3. `claude -p --model <model> --input-format stream-json --output-format stream-json --tools "" --strict-mcp-config --no-session-persistence` に、画像（base64）と本文を 1 つのユーザーメッセージとして渡し、結果の本文を保存する。
4. 各解答を `classify.py` で分類し、条件ごとの P(recursion) と ΔP を集計する。

```bash
python -m pip install pillow
python symbols.py symbols
python run.py --model opus  --n 20                         # 第 1 段階: 基準、赤ハート、青三角、テキスト指示、ノイズ、キャプション
python run.py --model opus  --conditions "shapes:red,colors:heart" --n 20 --tag stage2   # 第 2 段階: 図形と色の地図
python summarize.py runs/samples-opus.jsonl runs/samples-opus-stage2.jsonl --by-shape --by-color
```

### 解答の例（Opus 5.5、赤いハート）

再帰と分類された解答は、内側の関数 `dfs` が自分自身を呼ぶ。反復と分類された解答は、明示的なスタックと `while` で走査する。いずれも説明文はなく、コードだけだった。

```python
def inorderTraversal(root):
    result = []
    def dfs(node):
        if node is None:
            return
        dfs(node.left)
        result.append(node.val)
        dfs(node.right)
    dfs(root)
    return result
```

## 考察

**論文と一致した点.** 論文の中心的な主張は Opus 5.5 で再現した。(1) 課題と無関係な図形が解き方を変え、強い図形では直接指示と同じ 100% に達する。(2) 画像の代わりに同じ内容のキャプションを置いても、ノイズ画像を置いても起きないので、効果は言語化された内容ではなく視覚入力そのものによる。(3) 誘導の地図はモデルごとに違う。Sonnet 5.5 は 12 図形にほぼ無反応（最大 1/20）で、論文でも Sonnet 4.5 は Opus 4.7 と別の挙動（基準が 100% 再帰）を示した。

**論文と違った点.** 効く図形が違う。論文の Opus 4.7 は三角・ハート・円に色によらず反応し、枝分かれ矢印には反応しなかった。Opus 5.5 は螺旋と枝分かれ矢印に 100% 反応し、ハートには赤だけ部分的に反応し、三角と円にはほぼ反応しない。論文自身が、画像を文脈の末尾に置くと Opus 4.7 と GPT-5.4 で「螺旋や枝分かれ矢印のような、直感的に再帰を連想させる図形が最も強く誘導するようになる」と報告している（Appendix B.2.4、Fig. 15）。Claude Code では画像の前に長いシステムプロンプトがあるため、この「先頭でない配置」に近い。モデルの世代差（4.7 と 5.5）も関わるが、本再現では切り分けられない。

**システムプロンプトの影響.** ハートの効果はシステムプロンプトを 1 文にすると +0.22 から +0.62 へ上がり、論文の +1.0 に近づいた。論文の「画像を文脈の中ほどに置くと効果はほぼ消える」という観察と向きが一致する。一方、螺旋と枝分かれ矢印はシステムプロンプトの有無によらず 100% だった。形そのものが再帰を連想させる図形は配置に頑健で、ハートのように再帰との結びつきが恣意的な図形は配置に弱い、という読み方ができる。ただしハート 1 図形の結果にすぎない。

**Claude Code の利用者にとっての意味.** スクリーンショットや図を貼って作業を頼むのは普通の使い方であり、その画像の中の図形が頼んでいない実装方針の選択に影響しうる。本再現では、プロンプトが「画像を見て戦略を選べ」と明示した条件で効果を測っている。論文は「選べ」という語を外すと基準の強いモデルでは効果がほぼ消えると報告しており、通常の依頼文での影響の大きさは別に測る必要がある。

**本再現の限界.** 記号は 12 図形 × 12 色のうち 24 条件（論文は 288）で、描画は自前（論文の図形とは細部が違う）。判定は AST 規則で、論文の LLM 判定器は使っていない（サンプルを目視で確認した範囲では一致）。Claude Code の思考（thinking）の設定は論文の "effort = high" と揃えていない。画像を黙って置く条件（silent injection）と、プロンプトの言い換えは試していない。GPT や Gemini は対象外。
